# 实现参考

- [camscan](https://github.com/suhren/camscan) 提供摄像头扫描、页面整理及手工校正的桌面工作流参考。
- [OpenCV 的 squares 示例](https://github.com/opencv/opencv/blob/4.x/samples/cpp/squares.cpp) 展示多通道、多阈值产生四边形候选的方法。本程序独立实现纸面内外对比、几何评分和缺边回退。
- [OpenCV Document Scanner](https://github.com/andrewdcampbell/OpenCV-Document-Scanner/blob/master/scan.py) 展示文档四角筛选和透视校正的处理顺序。
- [µStreamer](https://github.com/pikvm/ustreamer) 提供了 Linux 下持续读取摄像头 JPEG 帧的参考。[Qt JPEG 插件](https://github.com/qt/qtbase/blob/5.15/src/plugins/imageformats/jpeg/qjpeghandler.cpp) 支持按显示尺寸解码，应用用同一帧的小图找边，映射到高清图。
- [ZBar](https://github.com/mchehab/zbar) 通过系统共享库读取二维码和条形码。
