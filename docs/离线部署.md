# 银河麒麟离线部署

本项目在银河麒麟桌面 V10（SP1）2403 的 ARM64 环境中验证。请用 `dpkg --print-architecture` 检查目标机架构。

程序、运行库和 OCR 模型必须与目标机的软件环境兼容。Windows 开发验证程序不能放到麒麟上直接运行。单独一个应用 DEB 也不包含全部运行依赖。

## 1. 先检查目标机

把高拍仪接到麒麟电脑，关闭可能占用它的摄像头软件。在源码目录执行：

```sh
bash scripts/probe-device.sh > device-report.txt 2>&1
```

检测工具只读取系统版本、架构、视频设备与可用格式等信息；不会安装驱动或修改权限。缺少 `v4l2-ctl` 时，报告会说明缺失，不会自动联网安装。硬件验收还需要在程序中实际预览和拍摄。

## 2. 在兼容环境构建

准备一台与目标机**相同 CPU 架构、相同麒麟发行版和系统更新基线**的构建机。优先使用同版麒麟系统；不能用一台较新的通用 Ubuntu 构建后直接声称兼容。

构建依赖：C++17 编译器、CMake、Qt 5 Core/Gui/Widgets/Concurrent/PrintSupport 开发包、OpenCV 4 开发包、dpkg-dev。实际 CMake 配置是依赖是否满足的判断依据。

在允许联网的构建机上，可从其官方软件源准备这些包（名称以该麒麟仓库为准）：

```sh
sudo apt-get update
sudo apt-get install build-essential cmake pkg-config ninja-build qtbase5-dev libopencv-dev dpkg-dev \
  tesseract-ocr tesseract-ocr-chi-sim tesseract-ocr-eng fonts-wqy-microhei qttranslations5-l10n ffmpeg libzbar0 xdg-utils libglib2.0-bin gvfs
```

这一步是构建机准备操作，不是目标机离线安装的一部分。不要把其他发行版的软件源加入麒麟系统。

在源码目录运行：

```sh
bash scripts/build-linux.sh
```

脚本配置、编译、运行测试后，再生成 DEB。任一步失败都会停止。输出在 `build-linux/`。默认同时使用 2 个编译任务，可使用 `BUILD_JOBS=4 bash scripts/build-linux.sh` 调整。

脚本默认通过 pkg-config 寻找 Qt 5，兼容部分麒麟 Qt 插件 CMake 配置异常的环境。在其他已验证的 Qt 环境中，可设置 `SCANNER_QT_PKGCONFIG=OFF` 使用 Qt 自带 CMake 配置。

## 3. 制作完整离线包

在上述允许联网的兼容构建机上执行，第二个参数必须是尚不存在的目录：

```sh
bash scripts/make-offline-bundle.sh \
  "$PWD/build-linux/kylin-document-scanner_0.2.2_arm64.deb" \
  "$PWD/offline-arm64"
```

DEB 文件名以实际生成结果为准。脚本只下载软件包和仓库索引，不安装系统软件；APT 状态文件保存在指定目录。使用空的已安装包清单求取依赖闭包，避免因为构建机已经安装某个依赖而漏装。

输出包括应用和依赖 DEB、中英文 OCR 模型包、本地 APT 索引、架构信息、构建环境记录、安装脚本和 `SHA256SUMS`。`offline-arm64/.apt`、`packages/partial` 和下载锁文件属于准备过程的缓存，分发压缩包中排除：

```sh
tar --exclude='offline-arm64/.apt' --exclude='offline-arm64/packages/partial' \
  --exclude='offline-arm64/packages/lock' \
  -czf offline-arm64.tar.gz offline-arm64
```

把整个离线目录或压缩包通过 U 盘转入目标机。交付前应在相同系统的干净环境里断网安装一次，确认依赖闭包有效。

## 4. 在目标机断网安装

解压后进入离线包目录：

```sh
sudo bash install-offline.sh --dry-run
sudo bash install-offline.sh
```

第一条只校验离线包并模拟依赖安装，不修改系统软件；第二条才执行正式安装。

安装器会依次校验所有分发文件的 SHA-256、CPU 架构、系统发行版、现有软件包状态和依赖解析结果。它只使用包内的 `file:` 仓库，不加载系统网络仓库，不下载互联网内容。

如果依赖安装需要升级、降级或移除现有系统软件，安装器会停止，要求使用更匹配的系统重新准备离线包。程序自身更新不受此限制。不要用 `--force` 绕过失败，也不要直接批量 `dpkg -i packages/*.deb`，否则可能替换不相关系统组件。

安装诊断记录保留在 `/tmp/kylin-scan-install.*`，安装器会显示具体目录。安装完成后以普通用户从应用菜单启动“文档高拍工具”；不应日常用 root 身份运行扫描程序。

## 5. 离线验收

- 拔掉网络连接，从应用菜单启动，确认中文正常显示。
- 在设备列表选择得力高拍仪，验证预览和所选实际分辨率拍摄。
- 连拍 30 页，检查页数和顺序；拔插设备后可重新连接。
- 处理一页歪斜文档并手动修正裁切，检查原图可恢复。
- 导出 JPG、PNG、普通 PDF、可搜索 PDF 和 TXT；打开 PDF 检查中文可搜索、可复制。
- 身份证正反面合并后检查两图完整、比例正确。
- 查看 OCR 状态；可用 `tesseract --list-langs` 确认包含 `chi_sim` 和 `eng`。

文字识别以清晰的印刷体文档为主要场景。手写、印章遮挡、反光和复杂表格需要人工核对；原始图像保留用于复核。

## 常见问题

**没有设备：** 先运行检测脚本，检查 USB 是否识别为 `2e5a:1719`，以及系统是否产生有效的视频采集节点。不要默认设备是 `/dev/video0`。

**设备被占用：** 关闭其他相机、会议或扫描应用，重新连接。程序不会强行结束其他应用。

**权限不足：** 由管理员检查当前登录会话的视频设备 ACL / `video` 组策略。不要采用全局 `chmod 777 /dev/video*`。

**无法完成安装：** 读取安装器显示的日志；确认包来自相同架构和系统基线。脚本报错不等于设备不兼容，也不能把安装成功等同于硬件验收通过。

**卸载：** `sudo apt-get remove kylin-document-scanner` 只卸载程序包，用户任务目录和扫描图片保留。依赖清理由管理员另行判断。
