# 文档高拍工具 0.2.2 使用说明

打开麒麟桌面的“文档高拍工具”。程序会连接得力 15165，在中央显示取景。顶部选择模式和裁切方式，展开“拍摄选项”可更换分辨率、选择输出格式或设置连拍。

默认在“文档/高拍仪输出”下保存首次拍摄的任务。若希望以后将照片放在数据盘，可在首次拍摄前点 **输出文件 → 更改目录**，选择数据盘上的文件夹。已有任务会继续把原图保存在该任务目录。点 **文件与设置 → 新建扫描任务** 可为新一批扫描指定位置。

## 自定义拍照快捷键

打开 **文件与设置 → 拍照快捷键**，点输入框，按一次想用的键或组合键，例如 F8，再点 **保存**。修改在当前窗口立即生效，关闭并重开程序后仍可使用。默认是空格，可用 **恢复空格 → 保存** 改回。输入文件前缀等文字时可正常打字。

## 清理拍摄缓存

打开 **文件与设置 → 清理拍摄缓存**，查看各项占用空间。默认清理的是移除页面后遗留的快照，以及编辑时产生的旧副本。

- 如需清空某个扫描任务，勾选该任务的页面，再确认永久删除。这会删除该任务的原图和处理图，包括尚未导出的页面。需要留存的页应先导出。单独导出的 PDF、JPG 等成品会保留。
- 如需一并腾出回收站空间，另外勾选清空系统回收站。这个选项也会永久删除当前用户从文件管理器及其他应用移入回收站的内容。
- 核对所选范围和预计释放的空间，再确认执行。快照会直接从磁盘删除。

## 连续扫描 A4 文件

1. 在顶部的 **模式** 中选 **文档**，将 **裁切** 设为 **自动裁切 A4**。纸张有一角斜缺时，可以直接放在桌面上拍，让缺口两端及相邻纸边清楚可见。如果一个角在镜头外，尽量让另外三个角及通往画外角的两段纸边入镜。
2. 确认取景框沿着纸张外沿后，点击 **扫描** 或按已设置的拍照快捷键。识别到纸张本身的缺角时，取景画面用黄色三角标出将补白的区域。程序对拍下的那一帧重新找边，按横向或纵向 A4 比例校正。缺口里露出的桌面或镜头未拍到的区域会补白。缺失的文字无法恢复。两角出框、整条纸边看不见等情况下，程序会在定位依据不足时保留整幅原图。
3. 每次拍完，左侧增加一页，主画面继续取景。翻到下一页后再按拍照快捷键。展开 **拍摄选项**，选 **定时连拍** 可以按设定间隔重复拍摄，点击 **停止连拍** 结束。
4. **扫描多页** 会把页面留在任务里。点左侧页面列表，按 Ctrl+A 选中全部，在 **拍摄选项** 中选 JPG、PNG、PDF、可搜索 PDF 或 TXT 并点 **导出**。**扫描单页** 会在每次拍摄后自动把选定格式的文件写入输出目录，仍保留原图。选 OCR 格式时一次拍摄还包括文字识别时间。
5. 点击缩略图可检查成品。若裁切需要修正，点 **页面工具 → 调整四角**，将四个点拖到原图纸角，再确定。**恢复原图** 可恢复未裁的扫描页。**应用当前效果** 可把所选颜色和裁切效果应用到当前页。
6. 如果多份材料固定放在同一位置，可以在取景时选择 **手动四角**，预先拖好四角，然后逐页扫描。**整幅取景** 保存整个画面。

## 工作模式

| 模式 | 操作 |
| --- | --- |
| 快速使用 | 默认自动裁纸，逐张输出 JPG。可导入已有图片。 |
| 拍照 | 默认保存整个取景范围的彩色照片。 |
| 文档 | 自动裁切 A4，连续拍摄多页。选中缩略图后可识别文字、复制或导出。 |
| 书籍 | 将平放的书脊对准取景中央，一次拍摄按中线产生左、右两页。曲面书页可能需要手工调整。 |
| 条码 | 拍摄或导入图片，选中含条码或二维码的页，点“读取条码”。 |
| 票证 | 分别拍摄证件正反面，Ctrl 多选两页，点“合并正反面”生成 A4 合成页。 |
| 电邮 | 选中页面后点“新建邮件”，通过系统默认邮件程序打开附有 PDF 的草稿。 |
| 复印 | 选中页面后点“打印所选页”，在系统打印窗口选择设备、页数和份数。 |
| 录像 | 选定分辨率后点击“开始录像”，结束时点击“停止录像”。无声 MKV 保存到输出目录。 |

## 重新打开旧任务

从 **文件与设置 → 打开扫描任务** 选择原有的 `session.json`。0.1.0 的 PNG 任务可以继续打开和编辑。备份时复制整个任务目录，包括原图、处理图及任务清单。点击“整理 → 从任务中移除”只会从任务清单移除所选页。

## 文字识别

识别和导出在本机进行。可搜索 PDF 保留图像并附文字层。中文词间可能出现空格，长句找不到时可试较短关键词，或导出 TXT 核对。条码读取采用 ZBar，条码边沿需要清晰并留有空白。
