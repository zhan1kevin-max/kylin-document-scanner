# 文档高拍工具

面向银河麒麟桌面的中文高拍仪应用，可用得力 15165 拍摄、裁切文件并导出多页 PDF。0.2.2 已在银河麒麟 V10 SP1 2403 ARM64 和该型号高拍仪上验证。图像处理和中英文文字识别都在本机完成。

## 扫描文档

接入高拍仪后，选择 **文档 → 自动裁切 A4**。取景框沿纸边定位，按空格拍摄，翻页后可以继续拍。纸张斜缺一角时，黄色三角标出补白区域。一个纸角在画面外时，程序也可根据可见纸边推算轮廓。原图会保存在扫描任务中，方便重新裁切。

- 在 **文件与设置 → 拍照快捷键** 中可以改用 F8 或自选组合键。
- 支持 JPG、PNG、PDF、可搜索 PDF 和 TXT，也支持书籍双页拆分、证件排版、条码读取和录像。
- **文件与设置 → 清理拍摄缓存** 可查看并永久删除旧快照。清空任务和系统回收站需要单独勾选并确认。

## 构建和安装

在与目标机匹配的麒麟系统上安装开发依赖，再于仓库根目录运行下列命令。脚本会编译程序、运行测试并在 `build-linux/` 中生成 DEB。[构建依赖与离线打包说明](docs/离线部署.md)

```sh
bash scripts/build-linux.sh
```

在已配置对应麒麟软件源的 ARM64 目标机上，可以安装生成的包。

```sh
sudo apt install ./build-linux/kylin-document-scanner_0.2.2_arm64.deb
```

安装后从应用菜单打开 **文档高拍工具**。扫描、快捷键和空间清理的完整操作见[使用说明](docs/使用说明.md)。
